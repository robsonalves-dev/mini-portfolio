## 📌 Projetos em destaque

### 1. MotoCar

Aplicação web e mobile para gerenciamento de veículos, consumo de combustível, custos por quilômetro, abastecimentos, viagens e histórico de utilização.

**Tecnologias:** Flutter, PHP e MySQL.

### 2. VaultGuard

Gerenciador de senhas e links desenvolvido com foco na segurança e organização de credenciais, com proposta de integração entre painel web e aplicativos.

**Objetivo:** organizar informações sensíveis e aplicar conceitos de autenticação, criptografia e segurança de aplicações.

### 3. Tetris Mobile

Jogo desenvolvido para celular, com foco em jogabilidade, interface e experiência do usuário em dispositivos móveis.

**Objetivo:** praticar desenvolvimento de jogos e criação de aplicações mobile.
